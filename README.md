# OpenPanora

OpenPanora is an open-source, Linux-first desktop application
for managing and monitoring IP cameras, DVRs, and NVRs.

## Planned features

- Device and channel management
- Live viewing with 1, 4, 9, 16 and 36-camera layouts
- Remote recording search and playback
- Timeline and calendar navigation
- Video export by selected time range
- H.264/H.265 support and automatic reconnection
- Secure credential storage

## Technology

- Rust
- GTK4
- GStreamer
- SQLite
- System keyring

## Status

Early development. Device compatibility is not yet verified.
